**Convention for v2_1b-00:**
- Add entry to `MIGRATIONS` array with `version: "3"`
- Use `columnExists()` guards for any ALTER TABLE
- Create new tables with `CREATE TABLE IF NOT EXISTS`
- Wrap work in `up(db)` callback
- Bump `DRIFT_SCHEMA_VERSION` to `"3"`
- No separate `migrations/` directory exists — migrations live inline in `drift-schema.ts`

**Verdict: PASS.** Convention is clear and well-documented. v2_1b-00 has a clean pattern to follow.
