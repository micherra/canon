## What happens if we try to start anyway

- **Without Gate A:** v2_1a-03 (canon-planner body rewrite) has no agent to amend. Wave 3 fails immediately. The whole v2.1a plan is predicated on the planner existing as a real agent.
- **Without HIGH closure:** L4 hook may ship with the wrong allowlist or without intent-routing prerequisites, producing user-visible false positives on canon-writer / canon-learner flows. First blocked doc edit destroys user trust.
- **Without pre-flight:** several PLANs cite facts the authors could not verify (migration-runner convention, worktree parent field, agent frontmatter). Implementors hit gotchas mid-wave.

Skipping these is not a shortcut; it is an invitation to pay the cost later at higher multiplier.
